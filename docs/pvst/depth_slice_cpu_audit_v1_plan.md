# 深度切片CPU审计固定规则（深度读取前登记）

基于27c82606465ca7c88f935a06859d8c1732673b79当前分支的冻结观测路径。
只取manifest train/real，每库按(source_id,video_id)排序取前三个不同来源，合计最多6段；
每视频居中min(24,N)连续帧。选择不使用深度、背景稳定程度或模型分数；缺项不替换。
先保存样本身份，再生成全部24帧RGB联系图、人工记录静态可辨背景ROI，然后计算深度。

CPU入口depth_slice_cpu_audit直接调用当前native_dense，使用原生回映网格，Z仅除固定s一次。
不读取fake/dev/test资产；不构建模型、不执行前端/特征提取，不安装依赖，不运行GPU。
新入口支持当前“可比性/规模”问题，调用者为本审计CLI，输出JSON和预览；没有现成深度单轴、背景对应审计入口，旧XYZ立方体计数不能替代。

RGB对应：ROI人工确认来自建筑/墙面/家具等静态背景，不能将同坐标当同物理点。
ROI内goodFeaturesToTrack最多200，quality0.02、间距7；LK窗口21/maxLevel3，双向误差≤0.75原生像素，7×7灰度补丁NCC≥0.9，目标仍在确认ROI。
深度不参与匹配或过滤。每相邻帧独立匹配，另做首帧到中间/末帧；原生取整像素读取深度及valid。
至少12个双端有效深度匹配且RGB匹配/检测≥50%才记可靠；不合格仍保留统计，不能混入可靠汇总。
深度覆盖率=双端深度有效数/RGB通过数；另报RGB通过数/检测数，避免低匹配率被掩盖。
对应是简单可复核图像对应，不是物理点GT；相机运动下深度差不自动归因为估计器漂移。

h={1/32,1/16,1/8,1/4}，每个固定d0=0和h/2都报告，不选择最优原点。
绝对整数floor、不裁尾、不逐帧重编号。每帧统计有效点/占据片/片成员分布/max和top4占比。
关系计数：窗口所有有效片单元；时间边同片号、所有严格过去帧→当前，深度边同帧所有不同片号有向边。
排除自身/空片、不加斜边、不物化矩阵。有历史比例分母为包括首帧在内的全部有效片单元。
跨片率分母=两帧均有有效深度的对应点；报告可靠邻接对池化值及各对计数，不以深度稳定性筛样本。

小检查只覆盖负floor/边界/空片和因果边；真实样本核对manifest/dense帧身份与PTS。
候选仅用于小审计，不冻结h/d0/窗口/维度，不把关系边数当实测显存。
