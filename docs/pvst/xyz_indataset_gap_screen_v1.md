## 6. 唯一优先后续实验（仅提议，未执行）
**先做“人工核验来源扩充、固定模型与更新预算”的两组对照。** 对照组保留原7来源前70%训练；扩充组仅加入本批技术和人工都确认的固定/近固定运动对象来源，新增来源先按原始source隔离、仍取同规则前70%。保留XYZ_TEMPORAL结构、初始化、scale/h、loss、8槽历史、优化器、阈值及这4对完整开发集，两组固定10260更新、一个共同seed；不同时改骨干或关系模块。只以这4对的逐来源及宏AP/Dice/误报判断，先完成人工确认再冻结实际规模。
