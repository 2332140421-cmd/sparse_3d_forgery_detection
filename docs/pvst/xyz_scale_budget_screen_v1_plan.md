# PVST v0.3 XYZ扩展尺度CPU计数计划

唯一新增薄入口xyz_scale_budget_screen，直接复用native_dense回映/有效性及旧counter精确整数键和stride8窗口定义。
它输出训练前节点证据，不生成新缓存/模型路由。旧select_v03_scale通过后会读开发坐标并冻结尺度，
因此本轮不调用该完整流程，也不改变它的默认行为。

固定fine0.25/0.5/1，coarse各2倍，fine≤200000且coarse≤50000。
先只读训练manifest/固定视频坐标，核对旧1/8同身份锚点2970629/1488042。
对[104,128)逐帧原生有效点计数，floor网格原点/冻结全局scale不变。
从0.25整数归并到0.5/1/2，成员权重始终是原始有效点数；104/116/127三帧直接floor比对全层坐标和成员数。
三个候选全不合格则立即停止；存在合格才检查原32训练视频/1932 stride8候选窗口，含原历史边界和尾段。
每帧计一次，使用前缀和；固定窗口已计帧复用计数。只检查阶段一通过的候选，不读开发/测试坐标或标签。

CPU独立worker CUDA_VISIBLE_DEVICES空，总限1800秒；复用已有bounded_process，只终止本进程组。
逐帧/窗口计数留derived，持续保存已完成范围；TIMEOUT/FAILED不能冒充预算失败或通过。
无GPU/模型构建/训练/前端/新权重，正式XYZ=null与原协议/报告/JSON不变。源码先提交再运行。
