四、研究目标与整体工作流
━━━━━━━━━━━━━━━━━━━━

研究目标：

在稳定或近稳定相机场景下，学习三维局部结构及其时序变化，用于视频检测、伪造帧识别和帧内像素定位。

整体流程：

原生视频帧与实际PTS
→ MoGe稠密XYZ、共同预训练视觉特征
→ 每像素独立几何编码与视觉编码
→ XYZ细体素切块、学习块内点分布
→ 细块视觉融合与粗体素上下文
→ 两尺度因果时空关系编码
→ 粗块回传细块、细块回传像素
→ 独立帧检测头与像素定位头
→ 全视频分数聚合。

“切块”的含义：

- 按三维空间位置进行体素化；
- 不是16×16图像格；
- 不是语义实例分割；
- 不需要预先知道身体部位或物体身份；
- 块投影到图像后的像素成员由XYZ决定，不要求是矩形；
- 块数随真实点分布变化；
- 不固定为64个query或256个区域。

同一体素表示同一空间位置，不代表同一物体或同一材料点。时空邻域学习跨块变化，不声称输出了真实物理点轨迹。

六、完整模型结构
━━━━━━━━━━━━━━━━━━━━

以下维度为本轮固定规格。

A. 两尺度体素切块

三维细体素边长：

h = 1/64

坐标已除以训练集固定尺度s。

细体素索引与中心：

v_i = floor(q_i / h)
c_v = h × (v + 0.5)

粗体素边长为2h，粗索引：

k = floor(v / 2)

保留全部占据体素，不丢弃singleton，不限制每块点数，不以异常得分筛除点。

本轮不搜索h。预检统计体素数量和占据分布；若发现单位或实现错误，修正并记录，不能根据开发分数挑选h。

B. 独立几何点编码：128维

几何输入为9维：

x_i^g = [
    q_i,
    (q_i - c_v) / h,
    (q_i - mean_{j∈v}(q_j)) / h
]

三部分各3维。

块均值只作为相对参考，原始每点坐标仍保留。禁止用块均值替代整组点，再复制成高维。

点编码器：

- MLP：9 → 64 → 128；
- GELU、逐点LayerNorm；
- 原生图像邻域3×3 depthwise卷积；
- 128 → 128通道混合；
- 残差连接。

输出：

g_i ∈ R^128

g_i必须保留至最终定位头。

几何无效位置在进入局部层和输出时正确屏蔽，不能由卷积bias变成有效几何点。内容边界、padding与空间tile边界要区分处理。

C. 学习块内结构：256维

先对同一细体素内的已学习点特征进行max聚合：

b_v = max_{i∈v}(g_i)

把块特征回传到每个点：

u_i = VFE([g_i, b_v])

VFE规格：

256 → 128 → 128
GELU与LayerNorm。

再形成细块几何：

G_v = BlockMLP([
    mean_{i∈v}(u_i),
    max_{i∈v}(u_i),
    log(1 + n_v)
])

BlockMLP：

257 → 256 → 256

输出：

G_v ∈ R^256

这里是先学习点，再进行点—块—点互动，最后汇聚，不是把XYZ先平均成三个数。

mean/max依然是压缩；保留g_i旁路用于像素细节，不宣称无损编码整组点。

D. 共同预训练视觉分支：每像素128维

采用本地官方AINPAINT视觉初始化：

https://github.com/MMLab-unitn/AINPAINT-CVIU26

核对实际代码及权重，不凭记忆假定内部接口。

要求：

- 冻结DINOv2 ViT-L/14 registers视觉encoder；
- 使用官方预训练decoder并允许decoder训练；
- 不加载旧V8的伪造分类checkpoint；
- 本轮不加入LoRA；
- 提取decoder分类前特征并投影至128维；
- 加入共同因果短时序块，时间核3、空间核3×3，采用深度可分离卷积与128通道混合；
- 时间只读取当前及前两帧；
- 正确回映到原生图像内容区域；
- 拼接原生RGB3和归一化UV2；
- MLP：133 → 128 → 128；
- 接原生3×3局部残差，得到a_i ∈ R^128。

如果使用448×448视觉输入，ViT-L/14图像token对应32×32×1024。CLS和register token不能混入图像网格。

原生RGB路径保留高分辨率像素输入；不能把低分辨率视觉token插值称为恢复了全部高频信息。

旧decoder中的BN冻结running statistics；新增模块用逐点或逐token LayerNorm。不要让tile大小改变归一化统计。

保留共同视觉像素logit m_i^vis，以及共同视觉帧logit d_t^vis。新增结构通过残差接入。

E. 细块视觉与几何融合

细块视觉：

A_v = mean_{i∈v}(a_i) ∈ R^128

融合：

Z_v^0 = LN(G_v) + LN(W_a A_v)

W_a：128 → 256。

因此：

Z_v^0 ∈ R^256

G_v是独立学习的几何表示；Z_v融合后是视觉与几何联合表示，不再称为纯几何通道。

二维对照必须使用同样的视觉内容，不能只有静态UV输入。

F. 粗块上下文：512维

对每个细块：

e_v = ChildMLP([
    Z_v^0,
    (c_v - c_k)/(2h)
])

ChildMLP：

259 → 256 → 256

粗块初始特征：

C_k^0 = CoarseMLP([
    weighted_mean_{v∈k}(e_v),
    max_{v∈k}(e_v)
])

weighted_mean按细块包含的点数加权。

CoarseMLP：

512 → 512 → 512

粗块提供更大范围上下文，不删除细块，也不替代点级表示。

G. 同帧全局上下文

在粗层时序编码前，使用8个512维全局上下文token：

- token读取同帧全部粗块；
- 再将上下文广播回全部粗块；
- 使用标准cross-attention与残差；
- token不产生分区、不分配像素、不替代占据体素；
- 不创建M×M的全帧稠密注意力矩阵。

这8个token不是V9的8个或64个区域query。所有点和体素继续保留。

H. 两尺度因果时空编码

细层：

D=256，4个attention head。

粗层：

D=512，8个attention head。

每个head均为64维；FFN宽度为4D。

两尺度分别使用三层稀疏因果注意力，时间膨胀：

d = [1, 2, 4]

每层对节点(t,v)，读取：

- 当前时刻t；
- t-d；
- t-2d；
- 每个时刻同尺度自身及周围26个空间索引。

使用全部已占据候选，最多81条边，不随机截成8个邻居。不制造不存在的空体素点。同帧自身保证合法注意力目标。

相对关系：

r_ab = [
    (c_b - c_a)/h_level,
    PTS_b - PTS_a
]

r_ab为4维，经过：

4 → 64 → head数量

生成每个head的相对位置偏置，加入attention logit：

attention_logit_ab =
    dot(Q_a, K_b)/sqrt(64) + relative_bias(r_ab)

采用标准pre-LN、attention残差和FFN残差，dropout固定0.1。

真实时间差必须与相应节点关系耦合，不能把间隔向量独立拼接到最后分类头。

细层与粗层时间路径并行，输入分别来自当前帧的细块和粗块初始表示。不能先完成细层三层时序，再串联粗层三层时序，却仍声称原感受野不变。

两尺度体素时间感受野：

1 + 2×(1+2+4) = 15帧

叠加共同视觉3帧时序后，最大原视频时间感受野：

17帧。

视频之间不传递状态，不建立跨视频邻居。

I. 粗到细回传

Z_v^out =
    FuseMLP(
        Z_v^ST + W_c C_{k(v)}^ST
    )

W_c：

512 → 256

FuseMLP为残差MLP：

256 → 512 → 256

输出细块上下文256维。

J. 原生像素定位头

每个像素回查所属细块：

E_i = [
    g_i,
    a_i,
    Z_{v(i)}^out
]

维度：

128 + 128 + 256 = 512

定位残差头：

- 512 → 128；
- 3×3 depthwise卷积；
- 128通道混合；
- 128 → 1，最后投影零初始化。

最终像素logit：

m_i = m_i^vis + Δm_i

像素概率：

P_i = sigmoid(m_i)

同块内不同像素必须保留不同的g_i与a_i，不能把一个体素logit复制给所有像素。

无有效几何的像素仍通过视觉路径获得预测，其几何和块上下文输入为零。

K. 独立帧检测头

帧描述符由以下组成：

- a_i的mean128和max128；
- g_i在有效几何点上的mean128和max128；
- Z_v按点数加权mean256和max256。

合计1024维。

帧残差头：

1024 → 256 → 128 → 1

最后投影零初始化。

共同视觉帧头：

mean/max(a_i)得到256维，
256 → 128 → 1。

最终帧logit：

d_t = d_t^vis + Δd_t

帧检测不强制由像素logit的LSE产生。像素定位与帧检测共享特征，但使用独立输出头。

L. 视频输出

使用全部实际帧：

d_video =
    logsumexp(d_1,...,d_T) - log(T)

温度固定1。

流式使用数值稳定的累计方法。不同视频不共享累计状态。

- 视频输出：每视频1个logit。

M1/M2由实际数据决定，不伪装成固定数量。

━━━━━━━━━━━━━━━━━━━━
八、本轮两个对照条件
━━━━━━━━━━━━━━━━━━━━

条件1：UV_PVST

- 使用相同视觉分支、点编码器、双尺度网络、时空层和输出头；
- 结构坐标改为二维UV，补零形成三通道；
- 推荐使用像素中心归一化：
  q=[2(u+0.5)/W-1, 2(v+0.5)/H-1, 0]；
- 细块边长1/32，对应横纵各64个分区；
- 粗块边长翻倍；
- 按相同方式构造9维点输入；
- 不读取XYZ、深度、三维有效性或三维生成的成员分区；
- 所有真实内容像素作为二维有效点；
- 结构支路也融合相同的视觉点特征。

条件2：XYZ_PVST

- 使用完整三维设计；
- 三维细体素h=1/64，粗体素2h；
- 几何缺失像素按前述视觉保留路径处理。

匹配要求：

- 参数量相同；
- 公共参数初始化相同；
- 相同训练和开发身份；
- 相同帧、标签、损失、优化设置及seed；
- 相同通道、层数、输出头和最大epoch；
- 不将3D分组用于UV条件。

实际块数、邻居数、FLOPs可能不同，应报告。该实验比较二维与三维空间组织方案，不声称是完全相同计算量下只替换一个坐标通道。

本轮不增加第三条件。三维时间边消融等待本轮完成后另行决定。

九、数据选择与标签
━━━━━━━━━━━━━━━━━━━━

本轮固定seed：

20260909

使用两个数据集：

1. ActivityForensics，简称AF。
   提供视频身份、实际媒体及伪造时间区间。
   当前已核实的公开资产没有可直接使用的fake空间mask。

2. ANAKIN。
   使用实际发布且对应明确的逐帧空间mask。
   mask表示编辑区域，不改称肉眼可见异常真值。

固定完整小样本：

- AF：8个训练source pair、4个开发pair；
- ANAKIN：8个训练source pair、4个开发pair；
- 每pair包含一条real和一条fake；
- 合计32条训练视频、16条开发视频；
- 使用这些视频的全部原生帧，不只抽几个clip。

从既有训练、开发角色中分别选择，禁止把测试样本移入训练。

选择方式：

- 身份稳定排序；
- 固定seed选择；
- ANAKIN尽量覆盖inpainting和splicing；
- 不根据历史预测分数选择容易样本；
- 若同一source存在多个候选fake，用预先固定的身份顺序选择并记录；
- 样本不足时说明缺项，不静默减少到另一套规模。

身份核对：

使用source_id、pair_id、role和视频SHA确认实际媒体。不能仅按pair_id建字典回退，避免历史上不同source同pair_id导致身份覆盖的问题。

AF标签：

- 用官方区间和实际解码PTS产生帧标签；
- real帧为0；
- fake缺失空间标注，不参与像素监督；
- 本轮空间监督统一来自ANAKIN，不混入“AF fake整帧为伪造区域”的伪标签。

ANAKIN标签：

- 精确匹配视频帧与mask；
- 非空mask帧为正，合法空mask帧为负；
- 配对real空间标签为全零；
- 对应未解决的pair不用于空间训练；
- 不通过截断或补帧掩盖错位。

本轮小样本用于判断完整模型能否学习及二维/三维初步差异，不作为最终论文总体性能结论。

十、前端与缓存

- 几何有效性；
- 原生尺寸、实际PTS和像素映射；
- 标注映射；
- 冻结视觉encoder的图像token。

不可缓存后当作固定训练输入：

- 可训练decoder输出；
- 128维点特征；
- 256/512维块特征；
- 时空编码结果；
- 512维像素融合特征。

━━━━━━━━━━━━━━━━━━━━
十一、训练损失、分块与更新
━━━━━━━━━━━━━━━━━━━━

损失采用标准：

L = L_frame_BCE
    + I_spatial_GT × (L_pixel_BCE + L_soft_Dice)

三项权重均为1。

soft Dice：

L_Dice =
1 - (2Σ(PM)+ε)/(ΣP+ΣM+ε)

ε固定并记录，两个条件一致。

归一化：

- 帧BCE按完整视频归一化；
- 同一视频同时含正负帧时，两类等权；
- 只有一类时使用正常均值；
- pixel BCE先按有效内容像素平均；
- 空间损失按标注帧平均，形成视频空间损失；
- 两个数据集的视频损失等权。

为了避免执行时自行选择更新粒度，本轮明确：

一次有效优化更新由一条AF训练视频和一条ANAKIN训练视频构成：

L_update = 0.5×L_AF_video + 0.5×L_ANAKIN_video

每个数据集16条训练视频，分别按固定随机顺序配对形成每epoch的16次有效更新。两个条件使用相同顺序。

视频可分块逐次backward、累积参数梯度；两个视频全部目标帧处理完后再clip和optimizer.step。不需要保留整段视频全部计算图。

每块损失必须使用完整视频的帧数、正负帧数和空间标注帧数做正确权重，不能简单把不同长度块的平均loss等权相加。

首版不添加video BCE：

- 使用帧监督训练；
- 视频采用固定LSE读出；
- 不为了视频损失保留数百帧反向图。

时间分块：

- 默认8个目标帧；
- 左侧最多16个上下文帧；
- 只在目标帧计算损失；
- 上下文参与完整可学习路径；
- 不detach历史来偷偷缩短感受野；
- 视频开头使用合法短历史和mask，不复制未来；
- 所有原生目标帧每epoch覆盖一次；
- halo重复输入不等于新增独立训练样本。

允许改变一次物化的目标帧数量，但有效更新和全视频损失权重保持一致。

优化：

- AdamW；
- 预训练decoder学习率1e-5；
- 新模块学习率1e-4；
- weight_decay=1e-4；
- 梯度裁剪norm=1；
- AMP；
- 最多30epochs；
- 不另外引入调度器搜索。

早停与checkpoint：

- 以AF开发视频AUROC作为唯一best选择指标；
- min_delta=0；
- 连续8轮不提升早停；
- 指标相同保留较早best；
- 同一个best用于全部视频、帧和空间指标；
- 另外报告epoch0和last；
- 不把不同任务的最佳epoch拼成一行。

这意味着本轮优先按检测目标选模型，同时观察空间表现；不能称其为按空间Dice选出的最优模型。

━━━━━━━━━━━━━━━━━━━━
十二、内存与计算实现
━━━━━━━━━━━━━━━━━━━━

必须先测量最大真实原生尺寸的完整训练块，完成前向、反向和参数更新，再给出成本估计。

参考张量量级：

720p内容像素为921600。

- 单帧128通道FP16约225MiB；
- 24帧单条128通道路径约5.27GiB；
- 几何和视觉两条路径同时物化约10.55GiB；
- 单帧512通道融合张量约900MiB。

这些不包含全部激活、梯度和优化器，不是训练峰值承诺。

优先采用：

- 冻结大视觉encoder；
- AMP；
- 激活checkpoint；
- 精确时间halo；
- 带halo空间tile；
- 按需生成融合特征；
- 完整视频梯度累积。

空间tile必须保持算法等价：

1. 基于完整帧坐标确定体素成员、块均值与索引。
2. 分块计算点特征，但跨tile的同一体素必须统一scatter归并。
3. 全体成员的max、mean和VFE广播不能改成各tile独立计算。
4. 完成块时空编码后，再分tile回传和像素解码。
5. 卷积halo按真实感受野确定。
6. 全局上下文token读取完整粗块集合。
7. 不以tile边界生成新的component边界。

如果在这些等价优化后仍无法满足24GB显存，完成可运行的真实尺寸测量，报告需要的显存与耗时。停止正式训练等待硬件决策，不删点、不降通道、不把原生输入偷偷改为256×256。

━━━━━━━━━━━━━━━━━━━━
十三、必要检查
━━━━━━━━━━━━━━━━━━━━

只保留直接影响本轮结论的检查：

1. 原生内容像素覆盖完整，padding不进入统计、loss和评价。

2. 视频身份、PTS、GT、原生坐标与预测回映一致。

3. 同块均值相同但内部点分布不同的输入，能产生不同几何表示；排除均值复制实现。

4. 点输入顺序改变但成员及像素索引对应不变时，块聚合结果不应依赖存储行顺序。

5. 未来帧改变不影响过去输出；真实Δt实际进入时空关系。

6. 整段前向与时间分块的目标输出一致；空间tile与整帧路径在小尺寸样例上输出和必要梯度一致。
   比较时固定随机性或关闭dropout，不能把随机dropout差异误判为分块错误。

7. 两个条件参数量和公共初始化一致，UV条件不读取XYZ或三维成员关系。

8. 新残差末端零初始化，首步前部梯度为零可能正常；至少两次真实更新后检查几何路径参与训练。

9. checkpoint保存重载一致。

10. 一个真实pair贯通前端、两个条件的前反向、原生像素回映和评价。

检查失败时修复当前实现，不用新增实验来绕过问题。随机模型输出不得作为检测性能结果。

十四、训练监测与正式评价
━━━━━━━━━━━━━━━━━━━━

Python每轮自动输出并保存：

- epoch与更新数；
- frame BCE、pixel BCE、Dice loss、总loss；
- 固定训练monitor指标；
- 完整开发集指标；
- 学习率；
- 本轮与累计耗时；
- GPU peak allocated/reserved；
- best epoch、早停计数；
- 当前状态。

至少保存：

- history.csv；
- curves.png；
- progress.json；
- best和last checkpoint；
- epoch0/best/last评价；
- 每视频指标；
- 固定可视化样例。

恢复checkpoint包含：

- model；
- optimizer；
- AMP scaler；
- RNG；
- 已完成epoch及必要进度；
- 冻结输入清单和配置身份。

训练monitor从训练集预先固定选择，两个条件一致；报告中注明它是monitor子集。最终best再对完整训练集进行评价，避免用小monitor冒充全部训练成绩。

AF指标：

- 视频AUROC、AP、Accuracy、Precision、Recall、F1；
- 帧AUROC、AP、F1；
- 阈值固定logit≥0；
- 提供混淆矩阵。

ANAKIN空间指标：

- Dice；
- IoU；
- pixel AP；
- real视频像素FPR；
- 概率阈值固定0.5。

沿用本地已冻结评价器的聚合定义，并明确记录按帧、按视频或pooled计算。两个条件统一。

空mask处理要明确：

- 不用全背景帧的Dice=1抬高fake定位结果；
- real空间误报单独报告；
- fake中的合法空mask帧保留负帧信息；
- 不给没有正像素的样本随意赋AP=1。

pixel AP不等于AP@IoU；帧AP不等于AP@tIoU。本轮不以现有输出冒充空间实例或时间区间检测指标。

固定可视化包括：

- 原图；
- GT；
- 预测概率图；
- 阈值0.5二值图；
- 对应帧分数。

概率热图统一0–1色阶，样例按身份和预声明时刻选择，不按预测峰值挑图。

判断训练情况时结合：

- 训练loss及训练指标是否改善；
- 训练与开发差距；
- best之后是否退化；
- GT覆盖与背景误报；
- 几何支路是否收到梯度。

不要单凭loss下降宣称训练充分，也不要单凭早停轮次认定过拟合。

十六、文献依据与借鉴范围
━━━━━━━━━━━━━━━━━━━━

本方案借鉴以下设计原则，不宣称完整复现这些模型。

1. VoxelNet，CVPR 2018

https://openaccess.thecvf.com/content_cvpr_2018/html/Zhou_VoxelNet_End-to-End_Learning_CVPR_2018_paper.html

借鉴逐点学习、块内汇聚、块上下文广播回点的VFE思想。
不照搬每体素随机限制点数的设置。

2. PVCNN，NeurIPS 2019

https://github.com/mit-han-lab/pvcnn

借鉴点细节与体素上下文并行、体素特征回传到点。
不把体素池化当成唯一表示。

3. Point Transformer V3，CVPR 2024

https://openaccess.thecvf.com/content/CVPR2024/html/Wu_Point_Transformer_V3_Simpler_Faster_Stronger_CVPR_2024_paper.html

官方配置：
https://github.com/Pointcept/Pointcept/blob/main/configs/scannet/semseg-pt-v3m1-0-base.py

借鉴分层通道与粗细表示回传，不照搬其点采样、裁剪和任务配置。本方案不是PTv3复现。

4. P4Transformer，CVPR 2021

https://github.com/hehefan/P4Transformer

借鉴局部时空结构联合编码、坐标与隐特征分离。
不照搬点数截断、时间降采样或非因果全片段注意力。

128/256/512是本方案固定设计，不是文献证明的本任务最优值。最终评价的是完整匹配二维/三维方案，而不是用文献宽度提前宣称效果。

### MoGe实际分辨率与等价路由重用

兼容缓存的MoGe调用接收256×256 letterbox，num_tokens=1200、resolution_level=0、use_fp16=True。
本地v2.forward按sqrt(1200)取整得到35×35 token网格，DINOv2Encoder内部重采样为490×490；
头部结果再插值回256×256输出相机XYZ。PVST从该真实稠密输出裁去padding，再线性回映至原生H×W；
有效性要求全部插值贡献有效。不从mu格均值恢复点，不宣称原生每点都有独立几何测量。
PVST共同视觉encoder另为448输入、32×32图像token；两者分辨率不可混写。

单视频滑动窗口只在内存保留当前需要的最多24帧原生输入及无参数体素路由（坐标、成员、计数、9维坐标输入）。
它不保留decoder输出、g/a/G/Z/C或时空特征；参数依赖的全部路径每块重算、完整反向。
关闭dropout后，路由重用与重新构造的输出及参数梯度一致。视频结束清空，不跨视频传状态。

稀疏注意力调用PyTorch标准scaled_dot_product_attention，仍逐query读取全部81候选，
以同一4维实际相对位置/PTS MLP形成加性bias；不限制邻居、不近似softmax。
关闭dropout时与显式标准attention的输出和q/k/v/bias参数梯度一致，训练dropout仍为0.1。
最终资源验收单独记录torch_sdpa执行后端，不沿用旧后端验收记录。
