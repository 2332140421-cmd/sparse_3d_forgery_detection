统计在两条fake的48个**实际原生网格**上计算，是跨帧累计像素观测数，不是独立物理点数。GT为空返回null；本批48帧GT均非空。没有先把细GT缩到几何网格。

15个未选像素全部位于7ogg04的第23帧（PTS=0.92秒，GT12,812像素，选入12,797）。其几何缓存与原生图均360×640，未经过尺寸回映；可定位到原缓存valid=false。缓存已合并provider mask与有限性条件，不能据此恢复provider内部为何判无效，更不能归因于伪造。728qx7为432×768→720×1280回映，当前GT中没有因回映排除的像素。

逐帧核对Video.frame返回的GT/RGB/valid原生尺寸、帧索引、PTS、选中XYZ有限性；实际S使用SlabPool源码相同的torch.where(valid.reshape(-1))[0]，与NumPy原生索引独立核对。slab_ids仍为floor(Z/.125)，无额外深度区间、片号范围或每片点数门槛。空片没有有效观测，不另删有效点。

高分辨率输入显式为`pvst_rgbd_slice_relations_v1/geometry/`，不是旧256场；resize valid完整复核为双线性权重≥1−1e−6且插值XYZ有限。未放宽valid、补造XYZ或修补GT。两个real只核对角色/视频SHA/身份及首24帧合法零GT，未套用其继承的fake pair mask字段。

**未进入SlabPool不等于RGB未进入整个模型。** 既有原生图像/局部解码支路仍读这些RGB像素；本轮只检查切片分支的候选输入索引，不测学习后的非零贡献。

## 5. 下一步优先级与证据边界

**优先排查特征保留，而不是修补输入覆盖或直接换训练集。** 当前编辑区基本进入切片候选，整体排除解释不受支持；存在数量上的同片混合，但编码/池化是否保留编辑证据尚未测量。后续需要合规的已拟合权重开展相应独立诊断，本轮不重新训练以补权重。

若研究命题强调动作/姿态改变，应承认当前8对没有明确A类；更换为AF又缺像素监督，不能把任务/标签差异隐藏成同一实验。当前统计不能证明特征可分、关系有效，深度自然不排除线索，覆盖高也不证明信息已保留。网络和正式训练集合保持不变。
