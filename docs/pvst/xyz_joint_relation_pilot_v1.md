## 1. 实际实现与冻结协议

工作区：`/media/njupt/8FCD3869E2FAB06F/chenyh/projects/pvst-geometry-dataset-screen`；分支`pvst-xyz-joint-relation-v1`。执行提交：`f2c17cad7721e7ed718597a6380e40b9aab9c489`。合同见[ADR-0044](../decisions/0044-xyz-joint-window-relations.md)及[实际配置](xyz_joint_relation_config_v1.json)。原探针、核查报告与旧成绩保留。

入口：[joint_experiment.py](../../research_tools/xyz_pilot/joint_experiment.py)；模型：[joint_model.py](../../research_tools/xyz_pilot/joint_model.py)。旧encode仅增加默认True的spatial参数，新模型明确以False取得关系前C0；旧入口默认与checkpoint形状不变。

```text
冻结通用DFormer四级观测 + XYZ/valid/RGB
→ 可训练多尺度融合、XYZ/块内相对位置调制、学习池化 C0
→ 两层D128/4头窗口自注意力，更新全部窗口块 R
→ 当前R_t回填32维 + local32/RGB16 → 像素定位
→ 当前逐块线性证据e → logsumexp(e)−log(N) → 帧logit
→ 帧logit均值 → 视频辅助分数
```

两层接替旧space/context，没有叠加旧关系模块。各层Q/K为归一化内容加XYZ中心MLP和相对PTS MLP，V为归一化内容；无显式距离bias、强制平滑、数量输入或状态监督。A按实际观测帧分组执行等价block-diagonal注意力；B开放窗口全部连接。两者均保留自身连接和逐块表示。窗口截止t、内部双向，只输出t，不读取t之后帧；重复槽保留实际帧身份，缺失不补未来。不要求历史共有键或跟踪物理点。

像素路径不受帧预测门控，几何无效像素仍保留视觉旁路。空块集合使用可学习空表示；块证据不是像素概率、注意力也不是异常真值。归一化池化不显式编码点数的限制仍保留，未据此加分支。

训练7对：40y1x9、95qvg9、9l8w54、4qwgw4、4ym5n4、76rjm7、9mygy9；开发4对：7e2e57、95q8g9、4xd3r9、7ogeg4。原角色隔离、官方GT、PTS不变，未访问测试集。fake40y1x9的6–9不监督、不计分，可作无标签历史。

复用2298帧现有通用冻结视觉/几何观测，新增MoGe=0、冻结视觉提取=0、下载=0。长边384等比工作网格、右下padding32、原生输出恢复规则不变；XYZ只除一次全局训练scale=12.699031352996826，h=0.5、原点0。全部工作网格有效点/非空XYZ块保留；这不是原生分辨率编码，也不是世界配准或米制重建。

## 8. 结论与停止

**事实：** 当前架构能较好拟合固定训练观察目标；开放历史连接没有提高末次开发宏AP，Dice/IoU/召回下降、real像素FPR略增。检测排序有部分增益，但没有形成一致的空间或检测改善。

**解释边界：** 现有结果应优先关注跨来源泛化及后期开发退化，不宜继续以“训练步数不够”解释这些固定观察目标；主要原因仍不能在特征、监督尺度、关系利用或编辑类型间单独确定。A/B只检验本架构跨时刻连接的增量，不能证明三维优于二维，也不能否定所有时空关系方法。新旧协议同时改变关系、读出和预算，不将旧成绩混成因果对照。

**唯一优先后续方向：** 若继续实验，先做预先固定较短预算与末次预算的后期泛化稳定性对照，避免继续加步数或同时改架构。本轮不执行它，也不以4410步替换本次主结果。
