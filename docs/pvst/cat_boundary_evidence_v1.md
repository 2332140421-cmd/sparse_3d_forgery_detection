# an:7e2e57猫与背景接缝：五固定帧核查

完成，退出码0。仅原fake帧0、30、60、90、119，视频120帧、1280×720。固定选择未按效果替换。人工记录“固定机位、新增猫经过、猫与背景融合不自然”作为观察来源，**不是三维异常真值**。

## 1. RGB与GT：接缝在哪里、标签标什么

第30、60、90帧能看见猫；猫的外轮廓（背部、头尾及足部与路面贴合处）呈贴片式融合观感，应对照无轮廓原图人工确认，不把黄色GT线本身误认为伪影。官方GT覆盖整只可见猫的身体、尾和腿，不是狭窄接缝标注。第0帧只在左侧边缘留极小GT，第119帧只在右侧边缘留极小残余，难以判断完整猫轮廓；两帧均无7px以外的GT内部，记不可比较，不换帧。

## 2. 深度：边界与前后关系

查看同色阶全帧及同框放大图，中间三帧猫所在区域的深度主要与路面渐变相连，未见沿尾部、四肢完整分离的清楚深度轮廓；部分上轮廓附近有颜色过渡，但不能把GT线附近的正常路面深度梯度当作伪造接缝。猫与外邻背景的深度中位数不同，亦包含像素位置及正常前景／背景差异，不是异常证据。

这五帧**未能确认明确不合理的遮挡次序或前后关系**，也没有独立真深度来判定深度估计是否准确。现有图不能证明猫与背景几何一致，更不能证明连续时序异常；细小边界错位仍需人工原尺寸检查。天空等紫色区域是几何无效，未补成真实深度。

## 3. 响应：接缝优先还是其他区域

没有看到持续沿整条接缝的亮环。中间三帧猫身上部／头部附近有局部较高logit，猫内部中位数高于内侧边缘带；并非“接缝有很强响应、只有猫身弱”。内侧边缘与外邻背景的logit中位数差在30/60/90帧约为+0.5091/+0.1578/+0.1126，后两帧差别较小；119帧反向，且GT仅83像素，不能概括为稳定边界证据。第60帧全图更强的响应还位于前景井盖／粗糙地面等非GT位置，不能只看猫局部色阶。

**唯一优先建议：先核对视觉特征对RGB融合痕迹的表达与背景纹理混淆。** 当前没有稳定的接缝优先响应，也没有明确的局部深度异常证据，不优先提出边界扩成整区或加入局部深度关系。只是本次固定帧读图判断，不证明特征完全没有信息。本轮不实施任何改动。
