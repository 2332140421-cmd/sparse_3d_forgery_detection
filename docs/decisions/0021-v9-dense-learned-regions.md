# ADR-0021: V9 稠密局部表示与学习区域有限对照

用户授权独立V9，取代本轮V8格均值前置编码路径，不修改历史V7/V8合同。
仅继承原始视频、精确官方区间与source split、冻结MoGe和ResNet18工具权重。
不使用追踪器、既有detector参数或标准化。

训练每视频最多四个32连续帧片段，验证28视频全部27505帧。三条件RGB_QUERY、
XYZ_QUERY、XYZ_PARTITION，同seed20260909、20轮、同参数初始化和优化预算。
逐像素12通道局部关系先编码，128视觉+128局部+RGB/UV投影256；64query汇聚，
唯一分区差别为归一化轴。区域self-attention、因果GRU256及像素注意力解码旁路
相同。像素/帧/视频使用归一化面积LSE。监督为clip BCE+0.5帧BCE，parent内
跨所有片段统一类别平衡，每source真假各半，处理完整pair后step。

区域是任务驱动软组织，不是对象/曲面发现；相机坐标XYZ不是统一世界物理运动。
无几何内容像素仍参与，无空间标签不报告空间性能。细节冻结在独立protocol。
