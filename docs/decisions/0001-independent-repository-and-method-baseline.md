# ADR 0001：独立仓库与方法基线

状态：Accepted

## Context

三维时空伪造研究需要一条不受既有代码结构和历史方法语义约束的新实现基线。旧仓库包含可供未来审计的工程经验，但不是新方法的代码或设计来源。

## Decision

- 新项目使用完全独立的 Git repository。
- 旧仓库不是代码基线、依赖、remote、submodule、subtree 或兼容目标。
- 旧仓库仅在用户明确授权时作为只读工程经验来源。
- 新项目采用稀疏三维粒子的正常时空演化学习主线。
- 不继承旧模型、旧检测逻辑、旧 feature schema 或旧训练路线。
- `docs/design_contract.md` 是新项目的初始权威方法基线。

## Consequences

- 所有数据契约、模型和实验代码都必须在本仓库中依据当前设计重新建立。
- 未来可能复用的是经重新审查的通用工程能力，而不是旧方法语义或兼容接口。
- 底层方法变化必须同步更新设计契约并以新 ADR 记录。

## Supersedes

无。本 ADR 是新仓库的初始决策。
