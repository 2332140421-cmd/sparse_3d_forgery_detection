# ADR-0049：全视频训练来源扩充配对

状态：用户授权，训练前冻结。

## Context

I/A/B在原4来源开发上均弱，同源后段改善没有延续为不同原视频收益。用户授权先使用第三批4对技术PASS素材试跑，不要求再次逐对确认。批次原话不能虚构逐ID内容/mask确认，明确已有排除仍优先。

## Decision

指定新增仅4ymrn4、4wge37、71gz67、4xeqd7中的实际可用来源，其他6对不修不补。新train角色仅写本协议；原7训练来源全视频合法目标，40y1x9 fake6–9不监督计分。dev4不改、无保留测试媒体访问。
固定原XYZLocalization/完整截止历史、scale12.880994319915771/h.5、工作长边384、两层128/4头、pixel BCE+Dice各1与原AdamW/BF16/clip。仅新增缺失帧补官方通用DFormer/MoGe观测，共享观测而非可训练C/R。原逐视频提取提为复用小函数；缓存读者可选根路径，默认行为不变。
从原initial.pt的XYZ完整随机初值严格加载，两组优化器全新。设Nexp为扩充全帧合法目标，U=10*Nexp，两组相同步数。扩充组无放回10轮，原7按相同seed+cycle算法循环并截断，不声称不同集合序列相同。训练前保存实际订单与曝光。仅新来源最大窗口一次实更新检查，丢弃后正式重置。
U/2和U保存权重、共同原7观察与新增观察分开、dev全824帧；末次主比较，24固定预览，不选best或追加预算。

## Consequences

扩充覆盖并改变每目标重复次数，只回答固定预算数据使用策略。全视频训练包括旧同源后段，后者本轮不再是未见评价。新增官方描述均移除，不据批次“新增”声称补足猫添加。开发已多次查看，不是最终测试。

## Supersedes

仅本独立实验覆盖ADR-0045的训练前70%范围、ADR-0048的冻结评价范围；旧实验结果、来源角色及默认入口保留。
