# ADR-0046：固定同源权重的时间读出分析

状态：用户授权，独立诊断。

## Context

同源探针B宏AP略升而Dice/召回下降，不能由不同训练权重A/B的差值直接解释历史输入作用。

## Decision

仅使用ADR-0045第10轮A/B、原444个后段目标及42固定预览。三条件A_CURRENT、B_FULL、B_CURRENT，B两条件严格同权重、共享其自身冻结C0；A不共享B编码。保持原模型、分区历史、尺度及精度，不训练或提取前端。
CPU先读取旧CSV按H0/H1–6/H7计算视频/来源等权统计，再前向回放A/B和同权重干预。回放警戒线在运行前固定为每来源/宏指标绝对偏差.001，逐帧差也完整保留；超界先停止归因。H0同权重像素logit必须一致。
每帧原生FP32 logit直接计算AP，GT内/外及real分别统计5/25/50/75/95分位数；来源分位数为逐帧同名分位数均值，不假装全像素池分位数。固定99阈值流式计数，按原层级绘制precision/recall/Dice/FPR，不拟合校准或选来源部署阈值。

## Consequences

同权重移除历史仅是输入机制干预，不替代匹配训练的A。历史分层与时刻/内容相关，不能证明冷启动因果；AP变化也不由整体置信度平移充分解释。所有曲线上界仅使用评价标签作诊断。只保存固定预览需要的缩放概率/二值，GT不进入模型。

## Supersedes

无。不修改ADR-0045的训练/主结果及原产物；仅登记本轮只读诊断范围。
