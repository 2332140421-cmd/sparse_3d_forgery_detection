# ADR-0045：同来源片段的视觉／XYZ空间／XYZ时空定位探针

状态：用户明确授权。

## Context

此前跨来源协议下固定训练观察拟合较强，开发效果弱。本轮只检验同来源未训练的后段定位，不作为跨来源泛化证据。

## Decision

仅原train7，配对real/fake按同一实际PTS区间的70%位置切分；训练PTS<边界、评价PTS>=边界，目标与历史都禁止跨分区。边界采用min首PTS+0.7*(max末PTS−min首PTS)，不从预测选边界。40y1x9_fake6–9仍只可作其分区历史。
仅用新训练段有效正Z按原每帧最多256点固定采样估计统一尺度，h=.5固定。复用原缓存，无新视觉/几何提取。
IMAGE_ONLY只用共同视觉融合/细节和同一像素解码器，context全零；XYZ_CURRENT/XYZ_TEMPORAL复用联合块编码与两层关系，只差同帧或因果窗口历史。所有有效点/块与无效几何视觉旁路保留，无新频域或状态支路。去掉未受监督的帧头/空帧读出参数，不报告其成绩。
同seed/优化器/精度/公共初始化，pixel BCE+soft Dice各1；全部合法训练目标无放回完整10轮，三组相同顺序。观察每训练视频合法序列1/3、2/3；第3与10轮评价，保存两份checkpoint，末次固定主比较。

## Consequences

I参数量与A/B不同，如实报告。I→A仅检验整个XYZ空间支路，不是几何独立贡献；A→B检验本结构历史增量。评价全原生画面AP/重叠/召回、real FPR与fake非GT背景FPR，空GT单列，不新定义AP@IoU或起止真值。小规模真实前后向通过后完成规定训练，不重复资源专项。

## Supersedes

仅本独立实验取代ADR-0044的跨来源开发、带放回14700步、帧BCE与两条件。原训练/开发角色、旧默认入口、权重和历史成绩保持不变。
