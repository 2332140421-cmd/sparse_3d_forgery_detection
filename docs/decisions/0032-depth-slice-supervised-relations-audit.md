# ADR-0032：片内先学习、时间/深度成对关系、真伪监督主线

2026-11-06；接受本轮设计修订及最多六段训练real的CPU审计，不授权模型或训练。
基于27c82606465ca7c88f935a06859d8c1732673b79，保持pvst-depth-slice-design分支。

取代ADR-0031中“推荐首版仅真实视频预测正常关系、整目标时刻遮挡”的主线地位；
其内容作为备选保留，不删除已接受决策，不与本主线同时实现。

当前主线见depth_slice_relation_design.md §4：
- RGB/有效XYZ/原位置先局部学习，再按相机+Z、d=Z/s、固定d0/h学习聚合；
  不用人工统计量替代C，保留像素映射与旁路，无效几何只门控、不强行归片。
- C同行时间、同列深度分别有独立参数，先时间再深度；每条边显式生成成对关系向量后聚合，
  使用实际PTS差及深度区间中心差，不加直接斜边，不宣称全对全等价。
- 主线真伪监督，允许当前和历史、不读未来；可靠帧监督才用于帧，没有帧标签不能整段复制视频fake标签。
- 首组对照匹配编码器/切片/时序上下文/数据/监督，比较直接汇聚与显式关系。
  三维增益需另设完全不依赖深度归片的二维对照；本轮不实施。

审计按预先固定真实训练身份选最多6段、每段最多24帧；RGB背景对应先于深度，
缺项不替换。native_dense原生回映、s只除一次。h=1/32..1/4、d0=0及h/2统一比较，
不按深度稳定性选样/边界；不冻结参数，不以节点边计数宣称训练可行。
旧PVST方法/模型/配置/失败记录仍只读，不引入其他分支模型。
