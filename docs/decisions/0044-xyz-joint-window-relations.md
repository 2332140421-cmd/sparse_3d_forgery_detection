# ADR-0044：窗口联合XYZ块关系与局部证据读出

状态：用户授权，独立实验。

## Context

旧探针各帧独立空间更新、只有当前块查询历史，帧头为块均值MLP。用户授权测试两层窗口联合交互；关系结构、读出、预算同时改变，不能以新旧差值单独归因。

## Decision

保留train7/dev4、冻结通用DFormer/MoGe观测及训练scale/h。几何调制和学习池化输出C0，旧encode新增默认True的spatial参数；新子类仅以False调用，不保留旧space/context/frame模块。
两层128维4头attention残差+FFN残差；Q/K=LayerNorm内容+XYZ中心MLP+相对PTS MLP，V=LayerNorm内容。A逐实际帧分组，数学上等价跨帧屏蔽；B完整窗口连接。自身可读、无未来、无共有键、全有效块保留。窗口截止t内部双向，唯一输出t。
R_t经原上下文回填参与像素输出；逐块线性证据log-mean-exp产生帧分数，空几何用可学习空表示。所有权重从同一新初始化训练，使用旧通用缓存而非旧取证权重。
每条件14700步、相同序列（前576与旧序列完全相同）、seed/AdamW/loss不变。固定训练观察56目标，开发完整824帧；不选best、不调阈值。一次最大真实窗口更新通过即训练，不重复资源专项。
配置、检查点含优化器/随机状态和身份，计算与Git发布分开。普通错误保留真实日志，修正须登记；无自动降规格或重试。

## Consequences

本实验衡量新架构中跨时刻连接的增量，不证明三维独立贡献或时间边界定位。normalized pooling不显式编码数量限制保留，不增加成员数或状态任务。显存与吞吐先实测，资源不足保留证据，禁止删块/改核心。

## Supersedes

仅在本独立实验取代ADR-0043的space/context、块均值帧MLP、576步预算及完整开发倒序检查。保留旧模型默认、来源角色、缓存、成绩和失败记录。将xyz_relation_review_v1的主候选转为本次明确配置，非通用框架。
