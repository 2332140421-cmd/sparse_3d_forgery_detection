# ADR-0048：独立原视频定位评价与新增来源人工页

状态：用户授权，冻结评价与数据准备。

## Context

同来源前70%训练/后30%评价是机制探针，不能替代正式目标中的不同原视频评价。需要同预算I/A/B判断后续优先方向，并准备未审训练来源。

## Decision

仅加载原定位模型I/A/B第10轮（10260步）；B完整继续第13轮（13338步）单列附表。严格加载，eval/no_grad、原BF16及FP32原生计分，dev4全视频824帧、自然冷启动，禁止再分70/30或跨视频历史。新实验标签不决定历史，显式使用原模型模式。
使用原scale=12.880994319915771、h=.5和观测缓存，不共享不同权重的C/R，不训练或新增前端。标签参考为原训练nearest降采样后沿输出bilinear恢复并以.5二值化；几何覆盖以模型实际工作valid最近邻回映原生与官方GT交集计算，同时保存工作网格覆盖。两者仅数据解释，不是模型上限或不可定位判据。固定24目标预览，不选阈值。
候选仅复用第二批34来源预筛、排除原已展示12及已有人审记录、dev/test角色和明显移动机位层；稳定/不确定分列，最多12，允许不足。不用模型分数、面积或痕迹强弱挑选。不修旧标注、不自动纳入训练。

## Consequences

主比较I10/A10/B10同更新预算；B13仅解释继续训练变化。训练覆盖仍只7来源前70%，开发已被查看而非最终测试。报告只提出一项首个后续对照，不实施。

## Supersedes

仅为本轮扩展ADR-0045的原dev4不参与评价范围；原同源机制协议、历史结果及方法默认不变。
