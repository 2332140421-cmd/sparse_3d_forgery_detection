# ADR-0027：V8空间监督扩量与匹配视觉适配

2026-10-30，Accepted，用户明确授权。

问题：在更多独立source及更广空间监督覆盖下，LoRA适配是否优于冻结视觉？

采用[唯一实验文档](../experiments/v8-spatial-supervision-expansion.md)与对应配置、冻结manifest。
保留原24/8角色，固定revision/seed、source隔离、原片一次固定预审及原技术标准；实际资格不足不放宽。
目前冻结29/20/20pair，train/dev均扩充；test_reserved不评分。纯视觉增量缓存不依赖三维统计/几何字段。
两条件同官方初始化、固定BN、空间损失和完整pair；仅LoRA可训练性不同。
最多四个完整pair计算配置探针，正式冻结关闭检查点/chunk4，保留分辨率与全部帧。
旧24pair模型只在新dev一次冻结参考推理，不能混作本轮匹配训练条件。

本独立扩量实验取代ADR-0026的固定24/8规模、单新训练条件及固定全部检查点/chunk2；
保留旧结果、模型与旧入口默认。报告完成与Git交付状态分开，保留真实退出与错误历史。
不声称三维/component贡献，不增加生产框架、额外seed或测试评分。
