# ADR-0039：冻结深度切片的当前／历史交叉关系定位读出

状态：已接受，2026-11-11用户授权；起点3aaf89f0785c1bc2861e894896dfe8b37311ef21。

问题：同一冻结C512下，同视频窗口历史是否比仅同帧其他片更有助于辨认编辑片？
仅新增独立探针，不改ADR-0036/37/38旧模型默认行为或结果，不预设历史有效。
直接调用者research_tools.rgbd_slice.slice_relation_experiment；小型readout模块输出当前每片logit。
旧集合模块只提供全局读出，不表达本对照的逐片交叉比较；因此单独读出及薄运行入口是最小必要实现。

数据：原last RGB_DEPTH_PARTITION epoch12/576，冻结编码器/SlabPool，仅原train8/48段1152唯一帧、dev4/8视频924帧。
沿实际native GT/valid/+Z/s/h.125及原24帧窗口/尾段左上下文。池化输出hook逐张量核对sets输入，在进入旧sets前停止；不使用旧关系/GRU/头输出。
每帧仅缓存全部C512、绝对片号、PTS、valid/GT计数；无像素特征或归属图落盘。所有有效片保留。

两组共用一层512维8head MultiheadAttention(dropout0)、同一参数和初始化。
Query=C+深度位置；Key=C+深度位置+实际PTS差位置；Value=候选C。
深度与时间分别用共享Linear(1,128)→GELU→Linear(128,512)，深度位置为原绝对片号×.125，时间是候选PTS−当前PTS。
CURRENT_ONLY仅同帧其他片；CURRENT_HISTORY再加本窗口已发生的全部片，不要求历史未编辑，不替fake拼接real历史。
按(帧,片槽位)排除当前自身，保留历史同号片；无候选才用同一个可学习512空参照。
R和C分别LayerNorm512后，concat(C_hat−R_hat,C_hat*R_hat)→Linear1024/128→GELU→Linear128/1。没有C旁路。
逐帧注意力不物化整窗N×N，允许逐帧反向/逐段一次更新，不删片或历史。
冻结前向保持原BF16、C本来为FP32；新读出用FP32。所有条件相同精度，不搜索。

片监督：有效GT像素数>0为正；空片不是样本；valid之外GT覆盖单列。train负片/正片比仅计算一次。
片段loss=各片加权BCE之和/本段有效片总数；逐帧立即backward但保留参数梯度，整段一次AdamW。
两组seed20260909、同初始state_dict hash、原orders.json逐轮顺序；12×48=576更新，lr1e-4/wd.01，无额外梯度裁剪或其他loss。
先在一个真实原训练片段完整前反向及更新验收，两组检查权重丢弃；从相同规定初始化正式开始。
不按开发选best/调参/加轮；每轮只记录loss与开发slice AP，最终回测原48段。

主指标：每fake帧全部有效片中正负均存在才算slice AP→视频均值→fake视频宏平均。
全正/全负/空帧计数，不补AP0。两条件评价帧与片集合必须相同。
辅助：最后分数原样回填片内valid像素，原生有效范围AP，另列GT覆盖。不称精细定位，不与原全画面像素头AP直接比较。
不以注意力作为异常分数；不声称物理因果、正确时间顺序或三维相对二维独立贡献。
若只有训练改善/少数视频主导，应直接报告；无收益不追加方格或重训。

必要测试：自身/未来排除、历史同号可读、首帧一致、GT计数及回映、尾段去重、逐帧归一化梯度。
