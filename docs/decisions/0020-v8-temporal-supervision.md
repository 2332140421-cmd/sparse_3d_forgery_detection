# ADR-0020：有限官方时间区间辅助监督

用户授权在独立`v8-temporal-supervision-pilot`分支做单seed20260909、固定5轮。
只对原面积LSE frame logit增加0.5倍辅助BCE；没有新增网络、逐格空间监督或新前端。
复用ADR-0019数据、初始化、训练顺序、优化器和完整跨块梯度，与原同seed5轮权重比较。
覆盖272视频234284原生帧，区间来自精确视频身份的官方映射，不使用V7数值资产。
不替代ADR-0019历史结果；仅本pilot放开“无帧标签”的监督限制，不声称空间真值。
主评价使用既有28开发验证视频。单seed无独立泛化结论，不自动补seed或调参。
