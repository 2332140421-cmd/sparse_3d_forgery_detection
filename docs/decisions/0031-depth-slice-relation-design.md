# ADR-0031：观看深度整片与真实关系预测（设计阶段）

状态：接受概念纠正及文档边界；实现、参数和实验协议待确认。依据本轮用户明确要求。
起点e05378d3d2c8a65d9b188190354463f2c3f3354a，独立分支pvst-depth-slice-design。

## 决定

按[设计稿](../pvst/depth_slice_relation_design.md)只沿观看深度d分片，
共享d0/h，保留原生UV/有效XYZ和可学习点特征，随后学习聚合得到C[深度片,时间,D]及观测掩膜。
当前MoGe前向轴是+Z，不把用户y记号等同数组Y；相机相对、单位lineage及跨帧配准缺口显式保留。
固定边界不等于几何已对齐；不得丢远点、补遮挡观测或以XYZ均值替代片内编码。

推荐首版固定独立训练的观测编码器，只用真实视频训练因果关系预测器；
遮整个目标时刻，主目标只比较有效非自身预测关系与观测关系，缺关系标证据不足。
观测编码器若需学习，独立真实可见数据监督后冻结；不与关系目标共同塌缩为常量。
片—帧异常不等于精确像素定位；通用attention汇总不等于显式关系行异常。
厚度、维度、时间窗、编码器和评估协议尚未冻结。本轮仅文档、手算，不授权模型实现或计算实验。

## 取代范围与保持项

本纠正仅取代“XYZ立方体调粗就等于沿观看深度整片”的概念混同，
不把ADR-0029/0030已接受的PVST体素方法改写成另一方法，不撤销其历史实现/配置/资源结论。
新设计在本分支独立登记，不移植其他分支模型，不覆盖V7/V8方法。
若后续实施，必须另行冻结方法与实验协议并匹配实现/检查；本ADR不自动放行训练。

## 本轮验证

源码及必要元数据核验；设计稿包含UV/相机XYZ一致的三点分片手算，
以及不偷读目标描述的关系行残差手算。未执行特征提取、全量计数、训练或GPU测试。
