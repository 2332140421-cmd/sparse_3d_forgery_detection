# ADR-0043：11来源紧凑XYZ块时序匹配探针

用户授权独立pvst-xyz-temporal-pilot-v1。只用固定train7/dev4，来源角色及人工/技术记录一次核对。40y1x9 fake 6–9不监督不计分，可作历史，不填正常标签。

本轮是等尺寸XYZ立体块，不是深度整片×图像格。原通用DFormer-S冻结视觉，无旧取证checkpoint/C；MoGe原版本和高分辨率兼容观测可复用。全图等比缩至长边384、32倍数padding；训练尺度仅训练有效正Z固定采样中位数；统一原点0，按预先候选选训练最大占据≤1024的最细h，不丢有效块。没有米制/世界配准保证。

可训练多尺度视觉投影，XYZ＋块内相对位置条件调制，点MLP、完整块内学习softmax池化→C128。当前空间4头交互后，同构跨候选读出：A当前，B过去0.7秒的8个PTS位置（含当前），无共有键前提、无未来。保留全部占据块与几何无效像素视觉旁路；块上下文映射回工作像素，预测恢复原生尺寸评价。

seed20260909，各576次更新，同初始化/目标序列/AdamW1e-4、wd.01、clip1。三项pixel BCE、softDice、frame BCE各1；每次一个目标完整历史梯度。末次权重主比较，无开发调参。一次最大训练窗口完整更新验收后自动训练A/B；B一次固定历史反序评价保持历史内容集合、当前帧与时间槽不变，不额外训练。原有模型/配置/成绩保持，不宣称三维独立收益或编辑起止定位。

实施配置以docs/pvst/xyz_temporal_config_v1.json及prepare后的训练尺度/h为准。此授权仅替代本独立探针中旧v0.2固定宽度、双尺度/训练范围和设计-only限制，不更改其历史定义或结果。
