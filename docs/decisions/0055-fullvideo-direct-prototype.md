# ADR-0055 完整视频原始XYZ块定位原型

状态：用户明确授权的限定实现与资源预检，2026-11-24。

## 问题、调用与最小边界

论文问题是完整edited片段的原始XYZ块能否在资源允许下直接跨时空交互，并输出全部帧。
新fullvideo_direct_model由fullvideo_direct_probe调用，输入冻结观测，输出逐帧定位；
新薄入口输出缓存身份、两步资源结果和终态。旧单目标8槽入口无法表达这个接口；不改旧默认，不建通用框架。

## 决定

按根契约17.12及用户交接固定DINO epoch01冻结观测、联合块编码、两层直接注意力和零初始化logit修正。
FRAME_ONLY/FULL_VIDEO同构同初值、各新AdamW两步，全片loss一次backward/step。无MoGe或正式训练/开发效果比较。
完整4ym5n4_fake由Codex短预检；中高病例仅交付终端脚本，用户启动，禁止持续轮询。

本独立原型取代ADR-0044/0045在此范围的因果窗口与当前帧输出限制；历史实验仍按旧契约解释。
设计对齐文档的中继只是提案，本轮明确不用，不声称近似计算等价。冻结二维和残差修正是本次选择，不代表用户思想必须如此。

## 验证

小张量比对旧MHA与SDPA输出/输入及参数梯度；Q分块完整K/V；checkpoint绑定逐帧输入；
全片R的跨未来依赖与FRAME_ONLY屏蔽；单尺度FP32路由、无效视觉旁路、零输出初值、全片合法监督平均；
真实低token片段两步梯度/更新、全部帧/点/块、缓存接口与冻结权重/BN不变。中高不承诺资源成功。
