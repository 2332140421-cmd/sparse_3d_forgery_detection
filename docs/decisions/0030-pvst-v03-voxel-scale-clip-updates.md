# ADR-0030：PVST v0.3 统一结构尺度与片段更新

接受；2026-11-03，依据用户本轮明确授权。研究问题仍是匹配UV/XYZ点—体素时空结构能否支撑视频检测与定位；本轮仅验证单4090上可执行性和各一轮学习/完整评价。

仅在v0.3取代ADR-0029及design_v02中XYZ fine=1/64、完整视频等权累积更新、每epoch全训练帧覆盖、最多30轮/best早停的规定。旧配置/入口/记录保留；v0.2 RESOURCE_BLOCKED及退出码1不改写。

XYZ从1/32、1/16、1/8中依次选择训练坐标窗口最大fine≤200,000且coarse≤50,000的最细候选。无候选满足则停止，不扩大搜索、删点或换样本。预算用于选择统一尺度，不是逐窗截断上限。UV仍1/32；coarse由fine整数坐标除2取floor建立。归一化沿用既有训练全局尺度。开发数据仅在冻结尺度后用于资源验收。

每训练视频最多4个不同stride8目标段；real/AN fake按时间分层seed20260909选，AF fake优先兼顾含修改与全正常段，不足从剩余真实候选补足。左右身份、PTS、标签来源冻结。最多16历史+8目标，逐片段目标帧均值frame BCE、AN pixel BCE+原逐帧softDice。有效更新AF/AN各一段顺序反向后按实际段数等权；不沿用全视频分母。新训练目标不与旧更新宣称等价。

保留全像素预测、所有有效点的编码与归块、原生点旁路、128/256/512、两尺度三层因果时空、全局context、真实PTS、原初始化/固定BN/AdamW/BF16/学习率等。体素调粗确实降低结构分支空间分辨率，点旁路不保证性能无损。MoGe dense256回映不解释为新增独立高分辨率观测。

实现复用现有PVST，仅新增research_tools/pvst/v03.py作为本轮独立CLI；直接输出独立v0.3协议、片段、资源case、epoch0/1 checkpoint与完整开发/固定训练monitor评价、报告及发布记录。旧train.main自动进入30轮且监督分母不同，不能直接用于本轮。没有新模型目录/框架。

通过必要正确性和最多3代表真实资源验收才执行两条件各一轮，验收权重丢弃。计算状态与Git发布状态独立，失败保留真实证据，不自动追加实验。
