# Architecture Decision Records

本目录记录底层、长期有效的方法与工程设计决策。

- 每项底层设计变化使用一个独立、递增编号的 ADR。
- ADR 至少包含 `Context`、`Decision`、`Consequences`、`Supersedes`。
- 已接受的决策不得直接删除或改写为相反含义。
- 改变既有决策时新增 ADR，并明确其取代关系。
- ADR 不记录临时训练参数、一次性调试选择或单次实验结果。
